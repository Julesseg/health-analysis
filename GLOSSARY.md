# Health Analysis

Personal health observations and behavior records used to explore associations over time.

## Language

**Input**:
A measured or logged variable selected to investigate its association with an output. A variable can serve as an input in one analysis and an output in another.

**Output**:
A measured or logged variable whose association with the selected inputs is being investigated. Calling a variable an output does not establish that the inputs cause it.

**Analysis window**:
The span of time over which an input or output is summarized for an analysis, such as a day, the preceding week, or the preceding month.

**Analysis period**:
The historical span of observations used to estimate a relationship. It is distinct from the behavior window summarized for each observation.

**Automatic discovery**:
Exploration of candidate input-output associations by the app without requiring the person to specify every comparison.

**Adjusted association**:
An input-output association estimated while accounting for other modeled inputs. Adjustment alone does not establish causation.

**Interaction**:
A relationship in which an input's association with the output varies with another input. Interactions are part of multi-input analysis alongside individual contributions.

**Default value**:
A configured value used when no log exists for a variable. It is an assumption rather than an explicit observation.

**Backdated entry**:
A log entry describing something that happened before the entry was recorded.

**Adjustment input**:
An additional input included when estimating an adjusted association. The inputs used for adjustment are visible and can be changed by the person running the analysis.

**Tracking variable**:
A named quantity, count, yes/no value, rating, or category recorded over time. A tracking variable can be selected as an input or an output.

**Confidence index**:
An assessment of the evidential support for an analysis's result, expressed as insufficient, low, moderate, or high. It is distinct from the magnitude of an association and does not establish causation.
