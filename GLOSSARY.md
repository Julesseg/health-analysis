# Health Analysis

Personal health observations and behavior records used to explore associations over time.

## Language

**Input**:
A measured or logged variable selected to investigate its association with an output. In a multi-input analysis, each input’s association accounts for the other selected inputs. A variable can serve as an input in one analysis and an output in another.

**Output**:
A measured or logged variable whose association with the selected inputs is being investigated. Calling a variable an output does not establish that the inputs cause it.

**Analysis period**:
The full available history over which the selected inputs and output have usable aligned observations.

**Discovery**:
A search the person starts to find strong associations among their tracking variables. It returns a short list of analyses the person can inspect and save.

**Adjusted association**:
An input-output association estimated while accounting for other modeled inputs. Adjustment alone does not establish causation.

**Interaction**:
A relationship in which an input's association with the output varies with another input.

**Default value**:
A configured value shown when no entry exists for a variable on a given day. It contributes to analysis only once the person explicitly records that value or confirms the day.

**Backdated entry**:
A log entry describing something that happened before the entry was recorded.

**Daily log**:
The manually tracked values for a selected day. Individually entered values are recorded as they are logged, while untouched values can retain assumed defaults until the day is reviewed.

**Day review**:
Confirmation of all displayed daily values together, including unchanged defaults. It is separate from recording individual entries.

**Saved analysis**:
A retained choice of inputs and output. It can be created manually or saved from Discover. Both refresh the same way over all eligible history.

**Tracking variable**:
A named quantity, count, yes/no value, rating, or category recorded over time. A tracking variable can be selected as an input or an output.

**Custom variable**:
A named tracking variable the person adds to their daily log, directly or by importing recorded values. It has its own history even when Apple Health contains a measurement with the same name and unit.

**Tracking start date**:
The first local day from which a custom variable applies to the daily log. Days without a recorded value can fall within its tracking period.

**Selected source**:
The single contributor whose readings are used for an imported Apple Health category. Readings from other contributors do not fill gaps in its history.

**Confidence index**:
An assessment of the evidential support for an analysis's result, expressed as insufficient, low, moderate, or high. It is distinct from the magnitude of an association and does not establish causation.
